# Política de Segurança

> [English version below](#security-policy)

## Versões suportadas

O llumo está em desenvolvimento inicial e ainda não teve uma versão estável publicada. Até a primeira release, apenas o branch `main` recebe correções de segurança.

| Versão | Suportada |
| ------ | --------- |
| `main` | ✅ |

## Reportando uma vulnerabilidade

**Não abra uma issue pública para relatar vulnerabilidade.** Issues são visíveis a todos e expor uma falha antes da correção coloca em risco os dados de assistidos em instalações que já estejam no ar.

Reporte pelo [GitHub Security Advisories](https://github.com/guilhermepolicarpo/llumo/security/advisories/new), que cria um canal privado entre você e os mantenedores.

Inclua no relato, sempre que possível:

- Descrição da falha e do impacto
- Passos para reproduzir
- Versão do llumo (ou o commit) e do PHP
- Sugestão de correção, se tiver

Você receberá uma primeira resposta em até **7 dias**. Como o projeto é mantido por voluntários, o prazo de correção depende da gravidade — mas manteremos você informado do andamento.

Pedimos que aguarde a publicação da correção antes de divulgar a falha publicamente.

# Security Policy

> [Versão em português acima](#política-de-segurança)

## Supported versions

llumo is in early development and has no stable release yet. Until the first release, only the `main` branch receives security fixes.

| Version | Supported |
| ------- | --------- |
| `main`  | ✅ |

## Reporting a vulnerability

**Do not open a public issue to report a vulnerability.** Issues are visible to everyone, and disclosing a flaw before it is fixed puts at risk the data of assisted persons in installations already running.

Report it through [GitHub Security Advisories](https://github.com/guilhermepolicarpo/llumo/security/advisories/new), which opens a private channel between you and the maintainers.

Whenever possible, include:

- A description of the flaw and its impact
- Steps to reproduce
- The llumo version (or commit) and PHP version
- A suggested fix, if you have one

You will get a first response within **7 days**. As the project is maintained by volunteers, the time to a fix depends on severity — but we will keep you posted on progress.

Please wait until a fix is released before disclosing the flaw publicly.
